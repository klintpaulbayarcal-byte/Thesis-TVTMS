MUNICIPAL TRAFFIC VIOLATION SYSTEM - START HERE
================================================

FIRST TIME
1. Install Node.js 20 or newer.
2. Open a terminal in this project folder.
3. Run: npm install
4. Copy backend\.env.example to backend\.env
5. Put the Supabase transaction-pooler connection string in DATABASE_URL.

LOCAL TESTING
1. Run: npm run dev
2. Open: http://localhost:5000/

PRODUCTION BUILD
1. Run: npm run build
2. Upload hostinger-app.zip through Hostinger hPanel:
   Websites -> Add Website -> Deploy Web App -> Upload your website files

HOSTINGER SETTINGS
- Framework: Express.js
- Node.js: 20 or newer
- Entry file: backend/server.js
- Start command: npm start
- Build command: leave blank
- Output directory: leave blank
- Database: use Database Connect Wizard -> Supabase
- Environment: copy the keys from backend\.env.production.example

IMPORTANT
- Plain FTP cannot deploy the Node.js backend.
- Never upload backend\.env or database credentials.
- No separate local web or database stack is required.
