# Professional Motion Update

The public landing page now uses a restrained motion system intended for an LGU/government portal.

## Included

- Fade, move, scale, and very slight rotation on scroll reveals
- Staggered entry for supporting cards and information blocks
- Subtle hover lift and icon movement
- Low-intensity desktop pointer tilt on the ticket lookup card
- Smoother modal entry and button press feedback
- Animated Lucide loading icons instead of emoji indicators
- Mobile and touch safeguards
- Full `prefers-reduced-motion` accessibility support

## Not changed

- Backend logic
- Database schema
- Authentication
- Plate-number and ticket-number lookup behavior
- Admin and officer workflows

The animation values are intentionally subtle to keep the interface professional and avoid a flashy or game-like appearance.
